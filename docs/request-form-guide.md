# 요청·문의 폼 만들기 가이드 (구글폼)

사이트에는 서버가 없어서 요청·문의는 **구글폼 링크**로 받습니다. 폼 주소(https)를 알려 주시거나 `scripts/build_catalog.js`의 `SITE.requestUrl`에 넣고 `node scripts/build_catalog.js`를 실행하면 아래 위치에 링크가 나타납니다. 주소가 비어 있으면 모두 숨겨집니다.

- 하단 "제품 추가 요청 · 오류 제보 · 문의"
- FAQ "찾는 제품이 없거나 정보가 틀려요"
- 검색 결과가 없을 때 "찾는 제품 요청하기"
- 제품 상세의 "가격·정보가 달라요? 제보하기"

## 권장 폼 구성
1. **어떤 내용인가요?** (라디오): 제품 추가 요청 / 가격·정보 오류 제보 / 기타 문의
2. **제품명 또는 제품군** (단답형, 선택): 예) 하기스 맥스드라이 팬티 4단계, 오버나이트 기저귀
3. **내용** (장문형, 필수): 쇼핑몰 링크나 가격을 알고 있으면 적어 주세요.
4. **답변받을 연락처** (단답형, **선택**): 답변이 필요할 때만 적어 주세요.

## 설정 권장
- "이메일 주소 수집"은 **끄기**(응답자 이메일을 자동으로 받지 않기)
- 파일 업로드 문항은 만들지 않기(개인정보·저작권 문제)
- 응답 알림은 운영자 메일로 받기

## 개인정보 안내 문구(연락처를 받는 경우 폼 설명란에 넣기)
> 연락처는 선택 항목이며, 답변을 드리는 목적으로만 사용하고 답변 후 삭제합니다. 연락처 없이도 제출할 수 있어요.

※ 수집 항목·목적·보유기간을 알리는 방식은 법령에 맞게 확인하세요(법률 자문이 아닙니다).

## 운영 팁
- 제품 추가 요청이 3건 이상 겹치는 제품군을 우선 조사해 목록에 넣습니다.
- 오류 제보는 쇼핑몰 링크로 확인한 뒤 반영하고, 확인되지 않으면 반영하지 않습니다.

## 적용 상태 (2026-11-23)
- 구글폼 응답자 링크는 `SITE.requestUrl`에 반영되어 있고, 사이트 안 **요청·문의 모달**(`index.html`의 `#inqModal`, `js/inquiry.js`)이 같은 폼으로 직접 전송합니다. 하단·FAQ·검색 결과 없음·제품 상세의 요청 링크는 모달을 엽니다(제품 상세에서는 "가격·정보 오류 제보"와 제품명이 미리 채워짐).
- 전송은 `fetch(no-cors)`라 구글의 응답 내용은 읽을 수 없습니다. 오프라인·차단 같은 **네트워크 실패는 구분해 안내**하지만, 구글이 거부한 경우는 알 수 없습니다.
- **사람이 해야 할 일(미확인)**: 사이트에서 실제로 1건 제출해 구글폼 응답 시트에 값이 정확히 들어가는지 확인. 이 개발 환경에서는 구글에 접속할 수 없어 시험하지 못했습니다.
- 폼 문항 번호(entry ID)가 바뀌면(문항을 지우고 다시 만들 때 등) `index.html`의 `name="entry.…"` 값도 함께 고쳐야 합니다.
- 폼 제목·헤더 배너에 옛 이름("아기쇼핑")이 남아 있으면 "아이톡톡"으로 바꾸세요.
