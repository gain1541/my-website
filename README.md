# 아기쇼핑 가격비교

육아용품(기저귀·분유·물티슈 등)의 쇼핑몰별 가격과 과거 가격 추이를 비교하는 정적 웹사이트입니다. PC·모바일 반응형입니다.

## 구조
- `index.html`, `css/style.css`, `js/app.js`: 화면
- `data/products.json`: 제품·브랜드·가격 데이터
- `data/prices_template.csv`: 가격 입력용 템플릿
- `scripts/build_catalog.js`: 제품 목록·브랜드 정보·CSV 템플릿 생성
- `scripts/import_csv.js`: 실제 가격 CSV 반영

## 가격 판단 기준
쇼핑몰별 최저가를 주 단위로 모아 최근 26주 평균과 비교합니다. 5% 이상 낮으면 저렴, 5% 이상 높으면 비쌈, 그 사이는 보통입니다. 기록이 4주 미만이면 **판단 보류**로 표시합니다.

## 실제 가격 넣기
1. `data/prices_template.csv`를 엑셀/구글시트로 열어 `price` 열을 채웁니다. (날짜는 확인한 날짜로 수정, 제품명 열은 참고용)
2. 저장한 CSV를 반영합니다.
```bash
node scripts/import_csv.js prices.csv
```
CSV 형식: `date,productId,shop,price,seller` (헤더 포함, seller는 선택).
예: `2026-11-30,p001,네이버 최저가,19650,11번가` / `2026-11-30,p001,쿠팡,20400,`

**입력 규칙**: 채널은 `쿠팡`, `네이버 최저가` 두 가지입니다. 가격은 **배송비를 포함한 실구매가**로 적고, 네이버 최저가는 그 주 최저가를 낸 판매처를 seller에 메모합니다.

 같은 날짜에 다시 넣으면 덮어씁니다. 새 날짜는 자동으로 추가되며, 과거 날짜 삽입은 지원하지 않습니다.

가격이 입력되지 않은 제품은 "가격 수집 전"으로 표시됩니다.

## 제품 목록 바꾸기
- `scripts/build_catalog.js`의 `add(...)` 목록을 수정한 뒤 `node scripts/build_catalog.js`를 실행하면 제품 목록과 CSV 템플릿이 다시 만들어집니다. (**이미 입력한 가격은 지워지니**, 가격 입력 후에는 `data/products.json`에 직접 항목을 추가하세요.)
- 등록 기준: 쇼핑몰 페이지에서 제품명·단계·팩 구성(매수/용량)이 확인된 것만 넣습니다. 팩 구성이 다르면 별도 제품으로 등록해야 가격 비교가 정확합니다.
- 브랜드 가격대(상/중/가성비)는 임시 분류입니다. 단위가격이 쌓이면 다시 조정하세요.

## 로컬 실행
```bash
python3 -m http.server 8000
```
`http://localhost:8000` 접속 (파일을 직접 열면 데이터를 불러오지 못합니다.)
