# 아이톡톡 가격비교

육아용품(기저귀·분유·물티슈 등)의 쇼핑몰별 가격과 과거 가격 추이를 비교하는 정적 웹사이트입니다. PC·모바일 반응형입니다.

## 구조
- `index.html`, `css/style.css`, `js/app.js`: 화면
- `data/products.json`: 제품·브랜드·가격 데이터
- `data/prices_template.csv`: 가격 입력용 템플릿
- `scripts/build_catalog.js`: 제품 목록·브랜드 정보·CSV 템플릿 생성
- `scripts/import_csv.js`: 실제 가격 CSV 반영

## 가격 판단 기준
제품마다 **배송비를 포함한 시장 최저가를 단가로 환산한 값**(기저귀·물티슈 1매당, 분유 100g당, 젖병·쪽쪽이 1개당, 로션 100ml당)을 날짜와 함께 기록합니다. 최근 6개월 기록의 평균과 비교해 5% 이상 낮으면 저렴, 5% 이상 높으면 비쌈, 그 사이는 보통입니다. 기록이 **4회 미만이거나 3주 미만**이면 판단 보류로 표시합니다.

상세 화면의 "네이버 가격 비교 보기" 버튼은 제품별 네이버 카탈로그 링크(`links.naver`)가 있으면 그곳으로, 없으면 네이버 검색으로 이동합니다.

## 가격 입력
1. `data/prices_template.csv`(또는 새 CSV)에 `date,productId,unitPrice,seller` 형식으로 적습니다. 예: `2026-11-30,p001,297.7,11번가`
2. 반영합니다.
```bash
node scripts/import_csv.js prices.csv
```
- 단가 = (배송비 포함 최저가 ÷ 수량). 예: 66매 19,650원 → 297.7원
- seller는 최저가를 낸 판매처 메모(선택)입니다. 같은 날짜·제품을 다시 넣으면 덮어씁니다.
- 입력 날짜는 불규칙해도 됩니다. 그래프는 실제 날짜 간격으로 그려집니다.
- 가격이 없는 제품은 "가격 수집 전"으로 표시됩니다.

## 제품 목록 바꾸기
- `scripts/build_catalog.js`의 `add(...)` 목록을 수정한 뒤 `node scripts/build_catalog.js`를 실행하면 제품 목록과 CSV 템플릿이 다시 만들어집니다. 이미 입력한 가격 기록은 **제품명이 같으면 유지**됩니다(제품명을 바꾸면 기록이 이어지지 않아요).
- 등록 기준: 쇼핑몰 페이지에서 제품명·단계·팩 구성(매수/용량)이 확인된 것만 넣습니다. 팩 구성이 다르면 별도 제품으로 등록해야 가격 비교가 정확합니다.
- 브랜드 가격대(상/중/가성비)는 임시 분류입니다. 단위가격이 쌓이면 다시 조정하세요.

## 로컬 실행
```bash
python3 -m http.server 8000
```
`http://localhost:8000` 접속 (파일을 직접 열면 데이터를 불러오지 못합니다.)
