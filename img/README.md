# 제품 사진 넣는 방법

- 사진 파일 이름을 제품 ID로 저장합니다. 예: `p001.jpg` (jpg, jpeg, png, webp 가능, 정사각형에 가까운 흰 배경 권장, 가로 600px 안팎·200KB 이하)
- 출처와 이용 허락 표기는 `credits.json`에 적습니다. 예: `{ "p001": "하기스 제공" }`
- 파일을 넣은 뒤 `node scripts/build_catalog.js`를 실행하면 자동으로 연결되고, 사진이 없는 제품은 아이콘이 표시됩니다.

## 넣어도 되는 사진
- 직접 촬영한 사진
- 브랜드나 제조사가 사이트 게시를 서면(메일 포함)으로 허락한 이미지
- 쿠팡 파트너스 등에서 제휴 사이트용으로 제공하는 방식(이미지 파일을 내려받아 올리지 말고, 제공되는 공식 코드를 쓰세요)

## 넣으면 안 되는 사진
- 쇼핑몰·공식 홈페이지·블로그에서 허락 없이 가져온 이미지(핫링크 포함)

## 예외: 쿠팡 파트너스에서 제공받은 상품 이미지
- 쿠팡 파트너스 상품 링크·배너 화면에서 받은 상품 이미지 주소 11개(p001~p003, p022~p027, p030, p031)를 `scripts/build_catalog.js`의 `COUPANG_THUMBS`에 넣어 **쿠팡 이미지 서버에서 직접 불러옵니다.** 파일을 이 저장소에 저장하지 않습니다.
- 사용자(운영자) 결정으로 적용했고, **쿠팡 파트너스 약관의 이미지 사용 조건은 아직 확인되지 않았습니다.** 약관에서 허용되지 않으면 `COUPANG_THUMBS`를 비우고 `node scripts/build_catalog.js`를 실행하세요(아이콘으로 돌아갑니다).
- 이미지가 로드되지 않으면 아이콘이 그대로 남습니다.
